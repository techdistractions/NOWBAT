NOWBAT - BUILD AND CONTRIBUTOR NOTES
=====================================

TOOLS
  JWASM.EXE    Assembles 8086-compatible source with -0 -omf.
  NBJWLINK.EXE Links .OBJ files into Win16 NE executables for Windows 1,
               Windows 2 and Windows 3.0 real mode.
  Python 3     Builds icons and ZIP archives on the host PC only.
  DOSBox-X     Optional for testing with separately installed Windows.

Both JWASM and NBJWLINK are external build dependencies and are not bundled.

BUILD
  MAKE          Compile both targets and independent test fixtures; write
                local-build ZIPs. No native tests required.
  MAKE2 ALL     Advanced developer build with static checks and fixtures.
  AUTOUAT ALL   Rebuild and run the three-Windows native test matrix.
  AUDIT REGRESSION  Seven native phases on three Windows versions.
  AUDIT INPUT / KEYBOARD / WINDOW  Focused GUI qualification.
  AUDIT STARTSHOT   Visible WAIT/SNAP/TAR/END diagnostic on all guests.
  DISTMAKE      Maintainer-only strict release qualification and packaging.

CONFIGURE
  MAKE accepts tools on PATH, tools in NOWBAT\TOOLS, or the full
  paths provided by JWASM_EXE and NBJWLINK_EXE. MAKE calls MAKE2,
  which also checks nearby tool/source folders. For explicit paths, create MAKE.LOCAL.BAT:

    @echo off
    set "JWASM_EXE=C:\path\to\JWASM.EXE"
    set "NBJWLINK_EXE=C:\path\to\NBJWLINK.EXE"

  MAKE2 additionally searches nearby tool/source folders for developer
  convenience. For native UAT, supply AUDIT.LOCAL.BAT with guest paths.
  Test machines require independently sourced Windows installations.

SOURCE
  SRC\         Script runtime, Win16 task UI, filesystem, SNAP and TAR.
  LINK\        NBJWLINK response files for WIN101 and WIN300.
  HOST\        Host-only packaging, resource and audit programs.
  TESTS\       Test scripts and fixtures. SCRIPT.TXT defines commands.

CONTRIBUTING
  Target the 8088 with 640 KB conventional RAM, no required EMS.
  Use 8086-compatible instructions, check DGROUP and code size, and keep
  WIN101 free of Win3-only API imports. Avoid platform-specific host paths.
  Comment source thoroughly: explain register contracts, Win16 ABI,
  buffer lifetimes, CPU/memory assumptions and compatibility workarounds.
  Keep end-user manuals free of development notes and project-specific
  references. HISTORY.TXT lists user-visible features and bug fixes only.
  Add/update tests for command changes. Check Windows 1, 2 and 3 real mode
  before declaring a new runtime release ready.
  For 0.0.54, see DOCS\REGRESSION_QUALIFIED.TXT. Public release still
  requires DISTMAKE and its separate AutoUAT matrix.
  Build success does not imply native test success: MAKE writes locally
  built binaries, while AUTOUAT records native behaviour.

Never bundle Microsoft Windows files or redistribute external tool binaries.
