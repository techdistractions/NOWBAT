NOWBAT - SCRIPT COMMANDS
========================

Run from inside Windows: NOWBAT.EXE SCRIPT.WAS
One instruction per line. Commands are case-insensitive. Use a leading
# or ; for comments and :NAME for labels. Quote paths containing spaces.
DOS 8.3 filenames are recommended. %NAME% expands a variable.

COMMAND: SHOWICON
SYNTAX: ShowIcon=YES or ShowIcon=NO
Show or hide NOWBAT's minimized task icon. Default: NO. On Windows 2/3,
the icon has Close, Switch To and About menu options.

COMMAND: LOGFILE
SYNTAX: LOGFILE "file.log"
Create/truncate a log and select it for subsequent output.

COMMAND: LOG
SYNTAX: LOG "message"
Write one line to the selected log (WAS.LOG by default).

COMMAND: LOGCLOSE
SYNTAX: LOGCLOSE
Close the selected log.

COMMAND: SET
SYNTAX: SET NAME=value
Set a string variable (max 8; names up to 15 chars, values up to 95).

COMMAND: IF
SYNTAX: IF left EQ|NE|=|<> right [THEN] GOTO|GOSUB label
Case-insensitive string comparison after variable expansion.

COMMAND: GOTO
SYNTAX: GOTO label
Jump to :label.

COMMAND: GOSUB
SYNTAX: GOSUB label
Call a :label subroutine (up to four nested calls).

COMMAND: RETURN
SYNTAX: RETURN
Return from the current GOSUB.

COMMAND: ASSERT
SYNTAX: ASSERT left EQ|NE|=|<> right
Continue on success. On failure, report the error and request Windows
shutdown. Use IF/GOTO for a nonfatal check.

COMMAND: WAIT
SYNTAX: WAIT milliseconds
Cooperative pause, 0 through 59000 milliseconds.

COMMAND: MOUSEMOVE
SYNTAX: MOUSEMOVE x,y
Move the real Windows cursor to absolute desktop pixel coordinates.
Both coordinates are unsigned 0..32767; the actual desktop may be smaller.
RESULT=0 means USER readback matched both coordinates exactly.
RESULT=2 means invalid arguments (ERRORCODE=87) or clipping/unavailable
readback (ERRORCODE=0). No button transitions are generated by this command.
%MOUSEX% and %MOUSEY% query USER's current cursor position independently;
65535 indicates unavailable/negative readback. These values are read-only.
Use DOEVENTS to allow other applications to process pending events.

COMMAND: DOEVENTS
SYNTAX: DOEVENTS
Process up to eight pending task messages, cooperatively yield once, and
return. Works with SHOWICON=NO; does not wait for events or prove that an
application has finished repainting. RESULT=0, ERRORCODE=0 on completion.
Use a witness file and WAITFOR FILE when a definite state is required.

COMMAND: WAITFOR
SYNTAX: WAITFOR FILE "path" TIMEOUT milliseconds
Poll for an externally produced, readable file, yielding between probes.
TIMEOUT is mandatory, 0..59000 milliseconds (0 = one immediate probe).
RESULT=0 means the file opened and closed successfully; RESULT=1 means
timeout (ERRORCODE=0); RESULT=2 means a DOS access/close error with the
real DOS ERRORCODE. File-not-found and path-not-found are pending states.
No implicit SNAP or UI assertion is performed. Delete old witness files
before starting an application if the file is used as a readiness signal.
Wait times have 10ms clock resolution; actual scheduling is cooperative.

SYNTAX: WAITFOR WINDOW "Exact caption" TIMEOUT milliseconds
Wait cooperatively for a unique usable top-level window (case-insensitive
full caption, 1..126 characters). On success it becomes the selected window
without activation, so MOUSEMOVE REL and %WINX% etc. work immediately.
RESULT=0 found; RESULT=1 timeout; RESULT=2, ERRORCODE=87 duplicate or
unusable window/caption. Timeout clears the selection. TIMEOUT 0 probes once.
This does not assert paint completion; use a separate app witness if needed.

Example:
    DEL "STAGE2.OK"
    SHELL "TEST.EXE"
    WAITFOR FILE "STAGE2.OK" TIMEOUT 15000
    IF %RESULT% NE 0 THEN GOTO TEST_FAILED
    DOEVENTS
    WAIT 200
    SNAP "STAGE2.BMP"

COMMAND: SHELL
SYNTAX: SHELL "program.exe" ["arguments"]
Start a Windows NE application and continue immediately. Not DOS EXEC.

COMMAND: SHELLWAIT
SYNTAX: SHELLWAIT "program.exe" ["arguments"]
Start a Windows NE application and wait for its module to unload. This
is not a DOS child exit code. Saving/closing is the child's responsibility.

COMMAND: COPY
SYNTAX: COPY "source" "destination"
Copy one file; overwrite the destination. No wildcards.

COMMAND: MOVE
SYNTAX: MOVE "source" "destination"
Move one file. Across drives, copy then delete the source on success.

COMMAND: REN
ALIASES: RENAME
SYNTAX: REN "oldpath" "newpath"
Rename a file on the same drive without overwriting a target file.

COMMAND: DEL
ALIASES: DELETE, ERASE
SYNTAX: DEL "filename"
Delete one file; not recursive.

COMMAND: MKDIR
ALIASES: MD
SYNTAX: MKDIR "directory"
Create a directory; parent must exist.

COMMAND: RMDIR
ALIASES: RD
SYNTAX: RMDIR "directory"
Remove an empty directory.

COMMAND: CHDIR
ALIASES: CD
SYNTAX: CHDIR "directory"
Change the working directory.

COMMAND: DIR
SYNTAX: DIR ["filespec"]
Write matching DOS filenames to the active log. Wildcards supported.

COMMAND: PWD
SYNTAX: PWD
Write the current working directory to the log.

COMMAND: EXISTS
SYNTAX: EXISTS "filename"
Check whether a file can be opened for reading (not a directory test).

COMMAND: SNAP
SYNTAX: SNAP "file.bmp" [BPP=n]
SYNTAX: SNAP "file.bmp",x,y,x1,y1[,BPP=n]
Without coordinates it captures the full desktop;
without BPP it detects the current Windows display depth.
The default engine is FAST, using direct video memory for supported
1/4-bpp graphics modes. Unsupported modes/regions return RESULT=2 rather
than quietly running a multi-minute GDI capture. FAST region captures
require X and width to be multiples of eight pixels.
Use SNAPSAFE for graphics drivers and modes unsupported by FAST.

COMMAND: SNAPSAFE
SYNTAX: SNAPSAFE "file.bmp" [BPP=n]
SYNTAX: SNAPSAFE "file.bmp",x,y,x1,y1[,BPP=n]
Same filename, region and BPP arguments as SNAP, but always uses the
original GDI GetPixel implementation. It is slower, but supports unusual
video drivers and optional output depths 1, 4, 8 and 24 bpp.

COMMAND: TARCREATE
SYNTAX: TARCREATE "archive.tar"
Create/truncate an uncompressed TAR archive.

COMMAND: TARADD
SYNTAX: TARADD "file-or-wildcard"
Add a file or matching DOS filenames to the current TAR.

COMMAND: TARCLOSE
SYNTAX: TARCLOSE
Finish and close the archive. Always call this after TARADD.

COMMAND: END
SYNTAX: END
Close NOWBAT without closing Windows.

COMMAND: PASS
SYNTAX: PASS
Exit NOWBAT with an internal success status.

COMMAND: FAIL
SYNTAX: FAIL
Exit NOWBAT with an internal failure status.

COMMAND: SHUTDOWN
SYNTAX: SHUTDOWN
Ask Windows to end the session; confirmation dialogs may appear.

VALUES AND ERRORS
-----------------
%TIME% gives the current DOS clock in HH:MM:SS format. %DATE% gives
YYYY-MM-DD. Both are evaluated each time a script expands them, including
inside LOG, rather than being fixed when NOWBAT starts.

Example: LOG "SNAP started at %DATE% %TIME%"

%RESULT% and %ERRORCODE% describe the last supported operation. Filesystem
errors normally set RESULT to 1 and ERRORCODE to the DOS error rather than
stopping the script. %WINVER%, %SCREENW%, %SCREENH%, %BPP%, and
%DISKFREE(C)% (choose drive letter A..Z) are read-only environment values.
IF and ASSERT test string equality/inequality, not numeric ordering.

EXAMPLE
-------
ShowIcon=YES
WAIT 5000
SNAP "SCREEN.BMP"
IF %RESULT% NE 0 THEN GOTO FAILED
TARCREATE "SCREEN.TAR"
TARADD "SCREEN.BMP"
TARCLOSE
END
:FAILED
LOG "Screenshot failed"
END

COMMAND: WINDOWSELECT
SYNTAX: WINDOWSELECT "Exact caption"
Select a unique top-level window by its full case-insensitive caption (1..126
characters). Does not activate the window. Missing caption: RESULT=1;
invalid, duplicate or unusable client area: RESULT=2, ERRORCODE=87. A failed
selection clears the previous selection.

MOUSEMOVE REL,x,y translates the selected window's current client coordinates
to screen coordinates. Both offsets must be inside the client area. No
selected window, stale handle or invalid position returns RESULT=2,
ERRORCODE=87 without moving the cursor. Absolute MOUSEMOVE is unchanged.
%WINX%, %WINY%, %WINW%, %WINH% are read-only current client origin (screen
pixels) and size; 65535 means unavailable (negative origin uses unsigned
16-bit representation). Selection is checked again before every query.
See WINDOWFOCUS and the native mouse commands below; keyboard events are described below.

COMMAND: WINDOWFOCUS
SYNTAX: WINDOWFOCUS "Caption"
Select a unique top-level window and attempt activation; verify GetActiveWindow.

COMMAND: MOUSEDOWN
SYNTAX: MOUSEDOWN LEFT | RIGHT
COMMAND: MOUSEUP
SYNTAX: MOUSEUP LEFT | RIGHT
COMMAND: MOUSECLICK
SYNTAX: MOUSECLICK LEFT | RIGHT
COMMAND: MOUSEDBLCLICK
SYNTAX: MOUSEDBLCLICK LEFT | RIGHT
Uses native driver callbacks rather than synthetic window messages.
While a button is held, MOUSEMOVE delivers actual relative motion and verifies
the final live cursor position exactly. Overshoot reduces movement increments;
if the driver cannot reach the exact point, RESULT=2 ERRORCODE=0. Buttons
persist between commands. RESULT=2, ERRORCODE=87 means invalid input or
transition; ERRORCODE=50 means the native callback is unavailable.
%MOUSEHELD% is the injected button mask (1 left, 2 right), not physical state.

COMMAND: RELEASEINPUT
SYNTAX: RELEASEINPUT
Release mouse buttons and keys held by NOWBAT. Automatically attempted on exit.

Command: KEYDOWN key
Command: KEYUP key
Command: KEYPRESS key
  Case-insensitive A-Z, 0-9, F1-F10, ESC, BACKSPACE, TAB, ENTER,
  CTRL, SHIFT, ALT, SPACE, HOME, END, UP, DOWN, LEFT, RIGHT, PGUP, PGDN,
  INSERT, DELETE. Uses XT set-1 scan codes and native USER events, not
  window messages. Use WINDOWFOCUS and focus the desired control first.
  KEYDOWN retains the key; KEYUP releases it; KEYPRESS performs both.
  Invalid names, duplicate down or unheld up: RESULT=2 ERRORCODE=87.
  Unavailable native callback: RESULT=2 ERRORCODE=50.
  RELEASEINPUT, END and FAIL attempt release of script-held keyboard and
  mouse input. Does not release keys held by the human operator.

COMMAND: KEYCOMBO
SYNTAX: KEYCOMBO CTRL+SHIFT+F2
  One to three unique modifiers (CTRL, SHIFT, ALT), then one nonmodifier
  key from the list above; no spaces around +. Names are case-insensitive.
  Presses in order; releases in reverse order. Invalid chords emit no events.

COMMAND: TYPE
SYNTAX: TYPE "Ab 19!?."
  Native keystrokes, not WM_CHAR injection. Quoted argument, normal %NAME%
  expansion, printable ASCII 32-126, US keyboard layout, Caps Lock off.
  Literal double quotes delimit arguments; use variable expansion to supply
  a quote. Use KEYPRESS ENTER/TAB for control characters. Empty text is valid.
  TYPE validates the entire expanded argument before injecting any key.
  KEYCOMBO and TYPE require no keys held by the script; RELEASEINPUT first
  if needed. Do not physically hold modifiers while running either command.
  Invalid syntax, unsupported characters or pre-held keys: RESULT=2, ERRORCODE=87.
  On callback failure attempt release of all script-held keys, RESULT=2 ERRORCODE=50.
